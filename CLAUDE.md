# Portfolio – Instrucciones del Proyecto

## Rol y Objetivo

Sos el mejor desarrollador web del mundo. Tu misión es crear un portfolio profesional y creativo para un desarrollador Full Stack con experiencia sólida pero sin una gran cantidad de proyectos propios para mostrar. Hay que ser creativos: destacar habilidades, arquitectura, stack técnico y contribuciones reales dentro de entornos corporativos, presentándolos como logros concretos.

---

## Perfil del Desarrollador

**Full Stack Developer** especializado en aplicaciones web, sistemas de workflow y automatizaciones con IA.

Trabaja principalmente con **React, Go, SQL Server y REST APIs**, creando soluciones escalables con interfaces frontend limpias y arquitectura backend sólida.

### Áreas de Experiencia
- Sistemas CRM
- Integraciones de workflow con IA
- Plataformas de webchat
- Interfaces en tiempo real
- Sistemas de carga de archivos y adjuntos
- Integraciones de APIs externas
- Herramientas de automatización
- Widgets personalizados y componentes UI interactivos

**Enfoque actual:** Agentes de IA, orquestación de workflows y plataformas de automatización modernas.

---

## Experiencia Profesional

**Full Stack Developer** — (Empresa / Freelance)

Desarrollo y mantenimiento de aplicaciones web usando React, Go y SQL Server.

**Responsabilidades y logros:**
- Construcción de interfaces frontend dinámicas y componentes reutilizables en React
- Desarrollo de servicios backend y APIs en Go
- Trabajo con sistemas CRM y automatización de workflows
- Implementación de sistemas de carga de archivos y manejo de adjuntos
- Integración de APIs externas y herramientas con IA
- Desarrollo de widgets interactivos y funcionalidades de chat en tiempo real
- Optimización de consultas de base de datos y procesos backend
- Colaboración en arquitectura de sistemas escalables y soluciones de automatización

---

## Stack Técnico

| Área | Tecnologías |
|------|-------------|
| Frontend | React, JavaScript/TypeScript, HTML, CSS |
| Backend | Go, REST APIs |
| Base de datos | SQL Server |
| IA / Automatización | Agentes de IA, integraciones LLM, workflow orchestration |
| Herramientas | Git, Docker (si aplica), n8n (si aplica) |

---

## Directrices para el Diseño del Portfolio

- **Tono:** Profesional pero moderno. No corporativo en exceso.
- **Diseño:** Limpio, con buena tipografía, dark mode o esquema de color que transmita tecnología.
- **Creatividad:** Ante la falta de proyectos públicos, mostrar snippets de código, diagramas de arquitectura, descripciones técnicas profundas, y secciones de "cómo lo haría" o "cómo pienso".
- **Idiomas:** El portfolio debe estar disponible en **Español, Inglés y Portugués**.
- **Secciones sugeridas:**
  1. Hero / Presentación
  2. Sobre mí / About
  3. Stack tecnológico
  4. Experiencia
  5. Proyectos (o "Qué he construido" con descripciones técnicas detalladas aunque sin repos públicos)
  6. Contacto
